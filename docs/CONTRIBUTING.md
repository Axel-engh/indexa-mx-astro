## 📐 Convenciones de commits (one‑word)

Convención clara y simple basada en **Conventional Commits**:

- **feat**: Nueva funcionalidad
  - `feat: add user authentication`

- **fix**: Corrección de bug
  - `fix: correct login validation`

- **docs**: Cambios solo en documentación
  - `docs: update README setup section`

- **style**: Formato, lint, sin lógica
  - `style: apply prettier rules`

- **refactor**: Refactor sin cambiar comportamiento
  - `refactor: simplify navbar logic`

- **perf**: Mejora de rendimiento
  - `perf: optimize animation rendering`

- **test**: Tests nuevos o corregidos
  - `test: add unit tests for router`

- **chore**: Tareas rutinarias / deps
  - `chore: upgrade dependencies`
